================================================================================
              INSTALACIÓN DE NICO v2.1.0 PARA RASPBERRY PI
================================================================================

Este paquete contiene el intérprete y IDE de Nico para Raspberry Pi y
dispositivos ARM de 64 bits (aarch64).

CONTENIDO DEL PAQUETE:
  - Nico-2.1.0-aarch64.AppImage    Aplicación de Nico
  - install_appimage.sh            Instalador del sistema
  - LEEME-rpi.txt                  Este archivo

REQUISITOS:
  - Raspberry Pi 3, 4, 5 o dispositivo ARM de 64 bits
  - Raspberry Pi OS (64-bit) u otra distribución Linux ARM64
  - Permisos de administrador (sudo)
  - FUSE2 (para ejecutar AppImages): sudo apt install libfuse2

INSTRUCCIONES DE INSTALACIÓN:

1. Extraé este archivo compactado (si aún no lo has hecho)

2. Abrí una terminal en la carpeta donde extrajiste los archivos

3. Dale permisos de ejecución al AppImage:
   
   chmod +x Nico-2.1.0-aarch64.AppImage

4. Ejecutá el instalador con permisos de administrador:
   
   sudo ./install_appimage.sh Nico-2.1.0-aarch64.AppImage

5. El instalador creará:
   - Los comandos "nico" y "nico-ide" disponibles en todo el sistema
   - Accesos directos en el menú de aplicaciones
   - Una carpeta en su home: ~/nico-v2.1.0/ con ejemplos, documentación
     y código fuente

USO:

Intérprete REPL (modo interactivo):
  nico

Ejecutar un programa:
  nico ~/nico-v2.1.0/ejemplos/basicos/01_hola_mundo.nico

Abrir el IDE gráfico:
  nico-ide

DESINSTALACIÓN:

Para desinstalar Nico del sistema:

  sudo nico-uninstall

Nota: Esto no elimina la carpeta ~/nico-v2.1.0/ con ejemplos, documentación
y código fuente. Si deseas eliminarla también, ejecutá:

  rm -rf ~/nico-v2.1.0/

NOTAS TÉCNICAS:

- El IDE incluye un fix automático para sesiones Wayland (Raspberry Pi OS
  por defecto). Si experimentas problemas gráficos, podés forzar el modo
  X11 ejecutando: QT_QPA_PLATFORM=xcb nico-ide

- El intérprete incluye soporte GPIO/PWM mediante libgpiod para controlar
  pines de la Raspberry Pi.

MÁS INFORMACIÓN:
