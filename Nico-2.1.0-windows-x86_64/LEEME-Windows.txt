================================================================================
                   INSTALACIÓN DE NICO v2.1.0 PARA WINDOWS
================================================================================

Este paquete contiene el instalador de Nico para Windows 10/11 de 64 bits.

CONTENIDO DEL PAQUETE:
  - Nico-2.1.0-Setup.exe    Instalador de Nico
  - LEEME-Windows.txt       Este archivo

REQUISITOS:
  - Windows 10 o superior (64 bits)
  - Permisos de administrador para instalar

INSTRUCCIONES DE INSTALACIÓN:

1. Ejecute el instalador con doble clic:

   Nico-2.1.0-Setup.exe

2. Windows le pedirá permisos de administrador. Acepte.

3. Siga las instrucciones del asistente de instalación.

4. En la página de tareas, se recomienda marcar:
   - "Crear acceso directo en el Escritorio"
   - "Agregar Nico al PATH del sistema (recomendado)"

5. OPCIONAL (solo para desarrolladores):
   - "Instalar MSYS2 para compilar/extender Nico"

   Si solo quiere usar Nico, NO necesita marcar esta opción.

USO:

Después de la instalación, abra una ventana de CMD:

Intérprete REPL (modo interactivo):
  nico

Ejecutar un programa:
  nico "C:\Program Files\Nico\ejemplos\basicos\01_hola_mundo.nico"

Evaluar una expresión:
  nico -e "3 * 4 + 2"

Mostrar ayuda:
  nico -a

Abrir el IDE gráfico:
  - Desde el menú de inicio: busque "Nico IDE"
  - Desde CMD: nico-ide

DESINSTALACIÓN:

Para desinstalar Nico:

1. Panel de Control ? Programas y características
2. Busque "Nico" en la lista
3. Haga clic en "Desinstalar"

El desinstalador eliminará:
- Los binarios y código fuente de C:\Program Files\Nico
- Los accesos directos del menú de inicio y escritorio
- La entrada del PATH del sistema

MÁS INFORMACIÓN:

  - Documentación completa: C:\Program Files\Nico\docs\
  - Ejemplos de código: C:\Program Files\Nico\ejemplos\
  - Código fuente: C:\Program Files\Nico\src\ (intérprete)
                   C:\Program Files\Nico\nico-ide\ (IDE)
  - Repositorio del proyecto: https://github.com/DiegoMajluff/nico
